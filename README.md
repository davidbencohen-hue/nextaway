# Nextaway

Pages for Tilday (formerly Nextaway). The root index, privacy and support pages redirect to `tilday/`, so the URLs already set in App Store Connect keep working.

`tilday/` holds the Tilday home page, privacy policy and support page. They are the pages given to Google for
the app's Gmail access review (home page and privacy policy URLs on the sign-in screen), so keep the "Gmail and
Google user data" section of `tilday/privacy.html` accurate whenever the app's Gmail feature changes.
